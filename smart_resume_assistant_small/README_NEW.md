# 智能求职助手 Smart Resume Assistant

一个集成了大语言模型的智能求职助手平台，帮助求职者优化简历、分析匹配度并准备面试。

## ✨ 功能特性

### 🔍 核心功能
- **智能简历解析**：支持PDF、DOCX、TXT格式，使用大模型深度理解简历内容
- **智能职位匹配**：基于语义理解的精准匹配度分析
- **个性化优化建议**：提供专业的简历改进建议和学习计划
- **模拟面试练习**：生成带标准答案的针对性面试问题
- **自动降级机制**：大模型不可用时自动回退到传统解析方法

### 📊 分析维度
- **技能匹配度**：深度分析技能相关性和同义词识别
- **工作经验匹配**：智能理解工作经历的相关性
- **教育背景匹配**：学历背景与职位要求的匹配度
- **关键词覆盖率**：重要关键词的匹配情况
- **综合评分**：基于多维度的智能评分系统

### 💡 智能优化
- **技能提升建议**：个性化的技能学习路径
- **简历内容优化**：专业的内容改进建议
- **格式优化建议**：简历结构和格式改进
- **面试准备指导**：针对性的面试准备策略

### 🎯 面试练习
- **技术问题**：基于职位要求的技术面试题
- **行为问题**：软技能和团队协作相关问题
- **项目经验**：项目经历深度挖掘问题
- **标准答案**：每个问题都提供详细的标准答案和评分要点
- **难度分级**：初级、中级、高级问题分类

6. **访问应用**
打开浏览器访问：http://localhost:5000

## ⚙️ 大模型配置

### 方法一：配置文件（推荐）

复制 `config_example.py` 为 `config.py`，然后编辑配置：

**使用阿里通义千问（推荐）：**
```python
LLM_CONFIG = {
    'enabled': True,
    'provider': 'qwen',
    'qwen': {
        'api_key': 'your_qwen_api_key_here',
        'model': 'qwen-plus'  # 可选：qwen-plus, qwen-turbo, qwen-max
    }
}
```

**使用百度文心一言：**
```python
LLM_CONFIG = {
    'enabled': True,
    'provider': 'baidu',
    'baidu': {
        'api_key': 'your_baidu_api_key_here',
        'secret_key': 'your_baidu_secret_key_here'
    }
}
```

### 方法二：环境变量

**通义千问：**
```bash
set DASHSCOPE_API_KEY=your_qwen_api_key_here
set QWEN_MODEL=qwen-plus
```

**百度文心一言：**
```bash
set BAIDU_API_KEY=your_baidu_api_key_here
set BAIDU_SECRET_KEY=your_baidu_secret_key_here
```

## 📖 使用指南

### 1. 上传简历
- **支持格式**：PDF、DOCX、TXT
- **文件大小**：最大10MB
- **上传方式**：拖拽或点击上传
- **处理方式**：自动使用大模型解析，失败时回退到传统方法

### 2. 输入职位描述
- **内容要求**：完整的职位描述，包含职位要求、技能需求等
- **字数建议**：100-2000字
- **处理方式**：大模型深度理解职位要求

### 3. 开始分析
- 点击"开始分析"按钮
- 系统自动进行智能解析和匹配
- 等待处理完成（通常1-5秒）

### 4. 查看分析结果

#### 📊 匹配度评分
- **整体匹配度**：综合评分和等级评定
- **技能匹配**：技能相关性和覆盖率分析
- **经验匹配**：工作经验与职位要求的匹配度
- **教育匹配**：学历背景匹配度评估

#### 🔍 详细分析报告
- **技能分析**：详细的技能匹配情况和评分
- **经验分析**：工作经验的相关性分析
- **教育分析**：教育背景的匹配度评估

#### 💪 优势与不足
- **个人优势**：突出的技能和经验优势
- **薄弱环节**：需要改进的方面
- **改进建议**：具体的提升建议

#### 🎯 面试问题练习
- **问题类型**：技术、行为、项目经验等
- **难度分级**：初级、中级、高级
- **标准答案**：点击查看详细答案和评分要点
- **模拟练习**：隐藏/显示答案进行自我测试

## 🚨 故障排除

### 常见问题

1. **大模型解析失败**
   - 检查API密钥是否正确配置
   - 确认网络连接稳定
   - 查看控制台错误信息
   - 检查API额度是否用完

2. **文件上传失败**
   - 确认文件格式支持（PDF/DOCX/TXT）
   - 检查文件大小是否超过10MB
   - 确认文件没有损坏

3. **配置不生效**
   - 确保config.py文件在正确位置
   - 检查配置文件语法是否正确
   - 重启应用使配置生效

4. **分析结果不准确**
   - 确保简历和JD内容完整清晰
   - 检查是否使用了大模型解析
   - 尝试重新上传和分析

### 日志说明

- `从配置文件加载大模型配置成功`：配置加载成功
- `大模型解析器初始化成功`：大模型可用
- `使用大模型解析简历...`：正在使用大模型
- `使用传统方法解析简历...`：回退到传统方法
- `大模型面试问题生成完成`：面试问题生成成功

## 📈 性能优化建议

1. **首次使用**：大模型API调用需要时间，请耐心等待
2. **批量处理**：避免短时间内大量请求，注意API限制
3. **网络环境**：确保网络稳定，避免超时
4. **内容质量**：提供清晰完整的简历和JD内容
5. **缓存机制**：相同内容会复用之前的分析结果
